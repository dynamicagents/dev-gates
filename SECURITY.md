# Security Policy

## Scope

This repository is the development-only aggregator for the gates' repositories. It
publishes nothing: findings here concern the workspace itself (its scripts, its
submodule configuration, the shared skills). A finding in one of the submodules belongs
in that repository, under its own policy, and a sequence across the crossing between the
gates and the agents they reach belongs in `dynamicagents/dev-agents`.

## Reporting a Vulnerability

Please report security vulnerabilities through
[GitHub's private vulnerability reporting](../../security/advisories/new).

Please do not report security vulnerabilities through public GitHub issues.

We aim to acknowledge reports within 3 business days and provide an initial assessment within 7 business days.
